# Tic-Tac-Toe

A simple Tic-Tac-Toe game built using **HTML, CSS, and JavaScript**.

I created this project as a hands-on way to learn and practice JavaScript. Instead of only learning concepts separately, I used them together to build a small interactive game.

##  Features

- Two-player Tic-Tac-Toe game
- Players take turns as X and O
- Automatically checks for a winner
- Displays the winning player
- Disables the board after a player wins
- Reset the current game
- Start a new game

##  Technologies Used

- HTML
- CSS
- JavaScript

##  What I Learned

While building this project, I practiced:

- DOM manipulation
- `querySelector()` and `querySelectorAll()`
- Event listeners
- Functions
- Arrays
- Loops
- Conditional statements
- Variables and state management
- Working with `classList`
- Enabling and disabling buttons
- Implementing game logic

##  Purpose of the Project

The main purpose of this project was to improve my understanding of **JavaScript fundamentals** by applying them to a real, interactive application.

The project helped me understand how JavaScript can interact with HTML elements and respond to user actions.

##  How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Start playing!
